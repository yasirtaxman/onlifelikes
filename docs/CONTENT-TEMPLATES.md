# Content Templates

Reusable article blueprints. In the Studio, pick the matching **Article type**, then follow the block order below. Blocks in `[brackets]` are inserted with the editor's **+** menu.

Every article, regardless of type, also gets: SEO title · meta description (120–158 chars) · focus keyword · slug · featured image + alt text · category · author · 3–5 FAQs · 2+ internal links · related posts · honest review-method setting · affiliate toggle if it links to Amazon.

---

## 1. How-to article (`how-to`)

```
Intro: the problem + the promise (2 short paragraphs)
[Quick verdict — optional: the shortest correct answer]
H2 per step or technique (6–12 steps), each 1–3 paragraphs
[Callout: tip] halfway — the most common mistake
[Ad slot] after ~30% and ~70% of content
H2 "What to skip / common mistakes"
[Callout: "Start this weekend" — 3 first actions]
FAQ (4)
```
Schema: FAQPage. Affiliate: light — link to related buying guides instead of stuffing product cards.

## 2. Buying guide (`buying-guide`)

```
Intro: who this is for + what problem the products solve
[Quick verdict: the 1–2 picks most readers should buy]
H2 "What actually matters" — 4–6 spec bullets in plain language
[Ad slot]
H2 "Top picks at a glance" + [Comparison table]
H2 per product (4–7): [Product card] with rank, best-for label, pros/cons
[Ad slot] mid-list
H2 "Buying advice" — how to choose between them
[How we chose] — criteria + honest method statement
[Callout: note — prices and availability may change]
FAQ (4–5)
```
Schema: FAQPage + ItemList. Disclosure toggle: ON.

## 3. Product comparison (`comparison`)

```
Intro: the either/or question, honestly framed
[Quick verdict: who should pick which — both answers]
H2 "Head-to-head" + [Comparison table] (8–10 factor rows)
[Ad slot]
H2 "Where X wins" + [Pros & cons for X]
H2 "Where Y wins" + [Pros & cons for Y]
H2 "Who should choose which" — bulleted household scenarios
H2 "Our recommendation" — a real answer, with conditions
[How we chose / method note]
FAQ (4)
```
Schema: FAQPage (+ ItemList if both get product cards).

## 4. Best-under-budget (`best-under-budget`)

```
Intro: the budget line and the value philosophy (value ≠ cheapest)
[Quick verdict: the 2–3 items to buy if you skip the rest]
H2 "Quick comparison" + [Comparison table with typical price bands]
H2 per product (5–8): [Product card]
[Ad slot] ×2 spread out
H2 "How to spot real value" — 3–4 tests (weekly-use test, replace test…)
[How we chose]
[Callout: price bands are typical ranges, not live prices]
FAQ (4)
```
Schema: FAQPage + ItemList. Disclosure: ON.

## 5. Listicle (`listicle`)

```
Intro: the theme + how items were selected
H2 per item (10–15), numbered, 1 short paragraph each
Mix [Product card] (max 5–6) with idea-only entries
[Ad slot] ×2
H2 "Where to start" — top 3 from the list
FAQ (3–4)
```
Schema: FAQPage (+ ItemList if product-heavy).

## 6. Beginner guide (`beginner-guide`)

```
Intro: reassurance — what you *don't* need to know/buy
H2 "The basics in plain language" (define terms simply)
H2 "Your first steps" — ordered list, cheapest first
H2 "What to buy first" — 1–3 [Product cards] max
H2 "What to ignore for now" — hype filter
H2 "A 30-day plan" — [numbered list]
FAQ (5 — beginners have the most questions)
```
Schema: FAQPage.

## 7. Checklist article (`checklist`)

```
Intro: when/why to run this checklist
H2 per phase or room; each with a [bulleted list] of check items
[Callout: printable/shareable tip]
H2 "The 20% that matters most" — priority items if short on time
FAQ (3)
```
Schema: FAQPage. Great seasonal-traffic format.

## 8. Seasonal guide (`seasonal`)

```
Intro: the season's specific problem + timing (when to start)
H2 "Do these first" — time-sensitive items
H2 sections by area (outdoor, entry, kitchen…)
1–3 [Product cards] where a product genuinely helps
H2 "Skip these" — seasonal marketing traps
FAQ (3–4)
```
Schema: FAQPage. Set **Update due** to next season in the CMS.

## 9. Problem–solution guide (`problem-solution`)

```
Intro: name the problem vividly (reader recognition)
H2 "Why this happens" — brief cause explanation
H2 "The quick fix" — solve it today
H2 "The permanent fix" — system/habit/product
[Product card] only if the product is genuinely the fix
H2 "If nothing works" — escalation and edge cases
FAQ (4)
```
Schema: FAQPage.

## 10. Product alternatives guide (`alternatives`)

```
Intro: why someone wants an alternative (price, availability, fit)
H2 "What [original] does well" — fair baseline
H2 per alternative (3–5): [Product card] + "choose this if…"
[Comparison table]: original vs alternatives
H2 "Bottom line" — best alternative for each buyer type
[How we chose]
FAQ (3–4)
```
Schema: FAQPage + ItemList. Disclosure: ON.
